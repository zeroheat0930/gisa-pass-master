# v1.8.1 (+36) 릴리스 노트

1.8.0(+35) 은 스토어에 올리지 않는다. 그 빌드에는 아래 개선이 하나도
들어 있지 않다 — 실제로 앱을 풀어 보고 나온 피드백을 반영한 것이 전부
1.8.0 태그 이후 커밋이기 때문이다. **1.8.1 이 정식 배포본이다.**

## 앱스토어 "새로운 기능" 문안 (한국어, 그대로 붙여넣기)

```
복원 기출이 전 회차로 완성되고, 답 쓰기가 훨씬 편해졌습니다.

• 복원 기출 420문항 — 2020년 개편 이후 21개 회차 전부
• 답이 여러 개인 문항은 번호별로 입력칸을 나눠 드립니다
• 서술형 채점 완화 — 표현이 조금 달라도 뜻이 맞으면 정답
• 복원 기출 랜덤 20문제 모의고사 추가
• 회차별 합격률 화면 추가 — 필기·실기 합격률을 한눈에
• 문제은행에서 복원 기출과 AI 예상 문제를 따로 볼 수 있습니다
```

> 4,000자 제한 안. 더 줄여야 하면 위 세 줄만 쓰세요.

## 이번 버전에 들어간 것

### 1.8.0 에서 이어진 것

**복원 기출 전 회차 완성 (100 → 420문항).** 2020년 NCS 개편 이후 21개
회차 전부. 코드 문항은 전부 실제로 실행해 정답을 검산했고(C·Java·Python·
SQL·서브넷) 420문항 모두 원문과 일치했다. 원문 표·그림은 이미지를 직접
읽어 텍스트로 옮겼다.

**회차별 합격률 화면.** 필기 19개 회차 / 실기 21개 회차의 응시자·합격자·
합격률. 홈의 D-Day 바로 아래에서 들어간다.

**문제 속 표 렌더링 수정.** 파이프로 적힌 표가 좁은 화면에서 열이 어긋나고
행이 접히던 것을 실제 표 레이아웃으로 바꿨다.

### 1.8.1 에서 새로 들어간 것 — 직접 풀어 보고 고친 것들

**답이 여러 개인 문항의 입력칸 분리.** `1. 문장 / 2. 분기 / 3. 조건` 처럼
답을 여럿 요구하는 문항이 94개인데, 칸이 하나뿐이라 어떻게 나눠 넣어야
하는지 알 수 없었다. 이제 번호 라벨이 달린 칸을 답 개수만큼 만든다.

**서술형 채점 완화.** 정답 문장과 글자까지 똑같지 않으면 오답 처리되던
것을 핵심 키워드 기준으로 바꿨다. 실제 표본에서 오판 97건 → 1건.

**문제은행 입구 분리.** 복원 기출과 AI 예상 문제가 한 목록에 섞여 있어
무엇을 푸는지 알 수 없었다. 이제 입구가 셋이다 — 복원 기출 랜덤 20문제,
복원 기출 회차별, AI 예상 회차별.

**복원 기출 랜덤 20문제 모의고사.** 420문항에서 20문제를 뽑아 실전처럼
푼다. AI 예상 문항은 한 문제도 섞이지 않는다.

**홈에서 바로 복원 기출.** AI 실전 모의고사 버튼 바로 아래.

**학습 플랜의 실전 모의고사가 복원 기출로 바뀌었다.** 시험이 가까울수록
실제로 나왔던 문제를 푸는 편이 낫다. 단, '최종 오답 정리'·'가볍게 복습'
미션은 유저 자신의 풀이 이력이 재료이므로 건드리지 않는다.

**개발자의 한마디에 리뷰 요청과 문의 메일.** 주소를 탭하면 복사된다.
