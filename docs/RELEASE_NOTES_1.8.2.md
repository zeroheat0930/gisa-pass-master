## 1.8.1 까지 쌓인 것

**복원 기출 전 회차 완성 (100 → 420문항).** 2020년 개편 이후 21개 회차 전부.
코드 문항은 전부 실제로 실행해 검산했다(C·Java·Python·SQL·서브넷).

**직접 풀어 보고 고친 것들.** 답이 여러 개인 문항(94개)의 입력칸 분리, 서술형
채점 완화(오판 97건 → 1건), 문제은행 입구 분리, 복원 기출 랜덤 20문제 모의고사,
홈 진입점, 학습 플랜의 실전 모의고사를 복원 기출로 전환.

**회차별 합격률 화면.** 필기 19개 회차 / 실기 21개 회차. 홈 D-Day 바로 아래.

**문제 속 표 렌더링 수정.** 실제 Table 레이아웃으로 교체.

## 1.8.2 에서 새로 들어간 것 — 저작권 준수

이용자 눈에 띄는 변화는 작지만, 안 하면 라이선스 위반이 되는 것들이다.

### CC BY 4.0 의 네 가지 의무를 다 채웠다

제3조 (a)(1) 이 요구하는 것은 넷이다 — 저작자, 라이선스 종류, **라이선스 링크**,
**변경 사실**. 1.8.1 까지는 앞의 둘만 있었다. 원문은 문항이 이미지로 올라와
있어 우리가 읽어 텍스트·JSON 으로 옮겼으니 명백한 변경인데 그 공지가 없었다.
하나라도 빠지면 라이선스가 소멸한다(제6조 (a)).

복원 기출 회차 목록 상단 고지가 이렇게 바뀌었다.

```
출처: Life-Journey 블로그 (chobopark.tistory.com)
라이선스: CC BY 4.0 (creativecommons.org/licenses/by/4.0)
원문의 이미지·표를 앱에서 읽을 수 있게 텍스트로 옮겼습니다.
```

### 오픈소스 라이선스 고지 화면을 넣었다

이 앱이 쓰는 pub 패키지는 대부분 BSD·MIT·Apache 2.0 이고 셋 다 배포물에
저작권 고지를 포함할 것을 조건으로 건다. **1.8.1 까지 그 화면이 아예 없었다 —
실제 미이행 상태였다.**

홈 개발자 카드에 `문항 출처 · 오픈소스 라이선스` 줄을 넣었다. 누르면
`showLicensePage` 가 열리고 Flutter 가 빌드 때 모아둔 패키지 라이선스가 전부
나온다. 여기에 복원 기출 CC BY 고지(국문·영문), AI 문항 고지, 합격률 출처도
함께 등록했다.

### 출처의 라이선스 증거를 보관했다

`docs/license-evidence/` — 원문 HTML 6건과 SHA-256 해시, web.archive.org
스냅샷 타임스탬프, CCL 배지 스크린샷. CC BY 는 철회되지 않지만(제2조 (a)(1)),
저작자가 나중에 설정을 끄면 "그때 표시가 있었느냐" 를 우리가 보여야 하므로.
