# v1.8.0 (+35) 릴리스 노트

## 앱스토어 "새로운 기능" 문안 (한국어, 그대로 붙여넣기)

```
복원 기출이 전 회차로 완성되었습니다.

• 복원 기출 420문항 — 2020년 개편 이후 21개 회차 전부
  (기존 100문항 → 420문항, 2020~2024년 320문항 추가)
• 회차별 합격률 화면 추가 — 필기·실기 합격률을 회차별로 한눈에
• 문제 속 표를 또렷하게 정리해 좁은 화면에서도 열이 어긋나지 않습니다
```

> 4,000자 제한 안이며, 위 3줄이면 충분합니다. 더 줄여야 하면 첫 두 줄만 쓰세요.

## 이번 버전에 들어간 것

### 복원 기출 전 회차 완성 (100 → 420문항)
2020년 NCS 개편 이후 21개 회차를 모두 담았다. 이번에 추가된 것은
2024년 3·2·1회, 2023년 3·2·1회, 2022년 3·2·1회, 2021년 3·2·1회,
2020년 4·3·2·1회 — 총 16개 회차 320문항.

코드 문항은 **전부 실제로 실행해 정답을 검산했다**(C·Java·Python·SQL·서브넷).
420문항 모두 원문 정답과 일치했다. 원문 표·그림은 이미지를 직접 읽어
텍스트로 옮겼다.

### 회차별 합격률 화면
필기 19개 회차 / 실기 21개 회차의 응시자·합격자·합격률. 회차 평균을
큰 숫자로 보여주고, 회차별 막대와 전체 표를 함께 둔다.

### 문제 속 표 렌더링 수정
표가 본문 텍스트 안에 파이프로 들어 있어 열이 어긋나고 좁은 화면에서는
행이 중간에서 접혔다. 실제 표 레이아웃으로 바꿔 정렬을 보장한다.
