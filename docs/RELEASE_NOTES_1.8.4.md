# v1.8.4 (+44) 릴리스 노트

**코드는 v1.8.3 (+43)과 동일하다.** 1.8.3 이 App Store 에서 이미 승인돼 같은 버전 트레인이
닫혔기 때문에(Transporter 오류 90062·90186) iOS 업로드용으로 버전 번호만 올렸다.
변경 내역 전체는 `RELEASE_NOTES_1.8.3.md` 참고.

## 플랫폼별 배포 상태 (2026-10-14)

| 플랫폼 | 올린 빌드 | 비고 |
|---|---|---|
| Google Play | 1.8.3 (43) | 그대로 유지. 구글은 versionCode 만 커지면 되므로 44 재업로드 불필요 |
| App Store | 1.8.4 (44) | App Store Connect 에서 새 버전 1.8.4 생성 후 빌드 44 연결 |

다음 Play 업로드는 versionCode 45 이상.

## 스토어 출시 노트 (App Store "이 버전에서 업그레이드된 사항" / Play ko-KR)

```
3회차 시험(10월 25일)을 앞두고 첫 화면과 학습 흐름을 정리했습니다.

• 첫 화면에서 바로 AI 실전 모의고사와 학습 플랜으로 — 스크롤 없이 시작
• 2026년 1·2회 복원 기출 문제와 회차별 합격률(2026년 2회 포함) 수록
• 학습 플랜이 시험일을 알아서, 시험 뒤까지 이어지는 플랜은 미리 알려주고 맞는 길이를 추천
• 홈 D-Day가 시험 시작 시각 기준으로 정확하게 — 시험 당일과 직후 안내 추가
• 스파르타 오답노트에 초기화 버튼 추가
• 결제·복원·광고 보상 안내를 더 분명하게
• 시험일 표기 오류와 작은 화면에서 버튼 제목이 잘리던 문제 수정
```

## 교훈

App Store 에서 승인된 버전 번호로는 새 빌드를 올릴 수 없다. 승인 이후 수정판은
**빌드 번호가 아니라 버전 번호부터** 올린다.
